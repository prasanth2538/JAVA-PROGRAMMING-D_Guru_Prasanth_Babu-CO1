## 1. Project Overview

The Campus Smart-Parking System is a Java-based application developed using Object-Oriented Programming (OOP) concepts. It manages vehicle parking in a multi-floor university parking facility.

The system allocates parking slots, generates unique parking tickets, calculates parking fees and releases slots when vehicles leave.

## 2. Objectives

- To develop a smart parking management system using Java.
- To allocate available parking slots automatically.
- To generate unique parking tickets.
- To calculate parking fees based on vehicle type and duration.
- To implement Object-Oriented Programming concepts.
- To manage multiple floors and parking slots.
